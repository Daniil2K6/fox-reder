## 🔴 КРИТИЧЕСКИЕ ПРОБЛЕМЫ (Чинить СЕГОДНЯ!)

### 1. **Хардкод секрета JWT** 
- Файл: `backend/auth.py:14`
- Проблема: По умолчанию используется строка `"fox-reader-secret-change-in-production-2026"`
- Опасность: Любой может подделать токены и выдать себя за любого пользователя
- **Решение**: Обязательно установить переменную окружения `SECRET_KEY` или app не запустится в production

### 2. **CORS открыт для всех сайтов**
- Файл: `backend/main.py:61`
- Проблема: `allow_origins=["*"]` позволяет любому сайту делать запросы к API
- Опасность: Злоумышленник может украсть токен пользователя со своего сайта
- **Решение**: Ограничить до `localhost:3000` для разработки, указать конкретный домен для production

### 3. **Нет лимита размера на загрузку файлов**
- Файл: `backend/books.py:172`
- Проблема: Можно загрузить файл любого размера
- Опасность: Атака DOS - заполнить диск большими файлами
- **Решение**: Добавить лимит 50MB на загрузку

### 4. **Ошибки миграций БД молча скрываются**
- Файл: `backend/database.py:190`
- Проблема: `try/except/pass` скрывает все ошибки, app запускается с неправильной БД
- Опасность: Функции ломаются, но никто не знает почему
- **Решение**: Выводить ошибки в логи, прерывать startup при ошибках БД

**ИТОГО**: 4 проблемы, которые нужно чинить прямо сейчас! Это занимает **2 часа максимум**.

---

## ⚠️ ВАЖНЫЕ ПРОБЛЕМЫ (Производительность, 1-3 недели)

### 1. **N+1 запросы в БД (60+ запросов на загрузку)**
- При получении 20 книг: 60-80 запросов к БД (вместо 2-3!)
- Затрагивает: все списки книг, авторы, поиск
- Решение: Использовать JOIN вместо циклов, добавить индексы
- Ускорение: **60 запросов → 3-4 запроса** (20x быстрее!)

### 2. **Кэширование подсчетов лайков/комментариев**
- Сейчас: Каждый запрос пересчитывает количество лайков (медленно)
- Решение: Добавить колонку `like_count` в таблицу `Book`, обновлять при добавлении/удалении лайка
- Результат: Автоматически решает N+1 проблему + ускоряет сортировку

### 3. **Дублирование кода (200+ строк)**
- В `books.py` функция `BookOut` (преобразование в JSON) повторяется 7 раз
- Решение: Создать одну функцию `_book_to_out()`, использовать везде
- Результат: Убирает 200 строк дублирования

### 4. **Отсутствие rate limiting**
- Проблема: Любой может 1000 раз попытаться залогиниться за минуту
- Решение: Добавить лимит 5 попыток логина в минуту на IP
- Время: 2 часа
