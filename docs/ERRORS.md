# Исправленные ошибки

## 1. TTS озвучивает SSML теги

**Дата:** 20.04.2026

**Проблема:**
При воспроизведении книги TTS читал "speak", "prosody" и другие SSML теги как текст.

**Причина:**
В файле `backend/tts/service.py` использовались SSML теги для передачи текста в edge-tts:
```python
ssml = f'<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis" xml:lang="{language}"><voice name="{voice}">{final_text}</voice></speak>'
```

Также функция `_add_prosody` добавляла теги `<prosody>` для знаков препинания (? !).

**Решение:**
Удалены все SSML теги - используется plain text:
```python
communicate = edge_tts.Communicate(text, voice)
await communicate.save(tmp_path)
```

## 2. Не отображались метки персонажей

**Дата:** 20.04.2026

**Проблема:**
При нажатии "Показать метки" в настройках ридера возникала ошибка:
```
Error: Objects are not valid as a React child (found: object with keys {name, gender})
```

**Причина:**
В vblite2 формате персонаж хранится как объект `{name, gender}`, а не строка. React пытался вывести объект напрямую.

**Решение:**
Добавлена проверка типа персонажа:
```tsx
[{typeof para.character === 'string' ? para.character : (para.character as any).name}]
```

## 3. Не создавался struct.json файл

**Дата:** 20.04.2026

**Проблема:**
Книга загружалась, но содержание не отображалось.

**Причина:**
При ручном добавлении книги скрипт не создавал `.struct.json` файл, который нужен для structured контента.

**Решение:**
Добавлено создание файла:
```python
struct_path = file_path + ".struct.json"
with open(struct_path, "w", encoding="utf-8") as f:
    json.dump(parsed, f, ensure_ascii=False, indent=2)
```

## 4. Голос игнорировал gender персонажа

**Дата:** 20.04.2026

**Проблема:**
Персонаж "Багдан" (male) озвучивался женским голосом, хотя в данных указан gender: "male".

**Причина:**
Система выбирала голос только по первой букве имени (Б → female), игнорируя поле gender.

**Решение:**
Обновлена логика `_get_voice_for_character`:
1. Если указан character_gender → используем его
2. Иначе по первой букве имени

Также обновлены все парсеры и API для передачи character_gender.

## 5. Белый экран в приложении

**Дата:** ранее

**Проблема:**
Приложение не загружалось, белый экран.

**Причина:**
Повреждённый JSON в localStorage.

**Решение:**
Добавлен try-catch при чтении localStorage:
```tsx
try {
  const u = localStorage.getItem("fox_user");
  return u ? JSON.parse(u) : null;
} catch {
  localStorage.removeItem("fox_user");
  return null;
}
```

## 7. VOICE_GROUPS неправильно присваивал пол

**Дата:** 20.04.2026

**Проблема:**
Буква Ф-Я относилась к female, а должна была к male.

**Причина:**
Буквы Ф, Ш, Ц, Э, Ю, Я ошибочно отнесены к женскому голосу.

**Решение:**
Изменены группы:
- А-Л → female
- М-У → male  
- Ф-Я → male

## 9. Microsoft Edge TTS ограничения

**Дата:** ранее

**Проблема:**
pitch и rate не работали через SSML.

**Причина:**
Microsoft Edge TTS имеет ограниченную поддержку prosody в SSML.

**Решение:**
Используется базовый синтез без дополнительных параметров prosody.
