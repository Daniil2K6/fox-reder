# FoxBooks (fox-reder)

Веб-читалка с личной библиотекой, поддержкой **FB2**, **EPUB**, **TXT** и формата **VoxBook** (`.vb` / `.vblite`), озвучкой через **Edge TTS** и социальной обвязкой (публичные книги, комментарии, подписки).

Репозиторий: [github.com/Daniil2K6/fox-reder](https://github.com/Daniil2K6/fox-reder)

## Возможности

- **Учётные записи**: регистрация, вход, JWT-токены, роли (user/admin)
- **Личная библиотека**: загрузка книг, дедупликация по SHA256, управление сериями
- **Читалка**: непрерывный режим и по главам, тёмная/светлая тема, настройки шрифта
- **Озвучка**: Edge TTS — несколько языков и голосов
- **Публичная библиотека**: поиск, фильтры по жанрам, форматам, сортировка
- **Социальные функции**: комментарии, лайки, подписки на авторов
- **Админ-панель**: управление пользователями, книги, серии, модерация

## Быстрый старт

Требования: **Python 3.12+**, **Node.js 18+**.

```bash
chmod +x run.sh
./run.sh --dev
```

- Фронтенд: [http://localhost:3000](http://localhost:3000)
- API (документация Swagger): [http://localhost:8000/docs](http://localhost:8000/docs)

Учётная запись администратора по умолчанию: **`admin` / `admin`**

### Запуск только бэкенда

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### Запуск только фронтенда

```bash
cd frontend
npm install
npm run dev
```

Прокси к API настроен в `frontend/next.config.js` (переписывание `/api/*` → `http://127.0.0.1:8000`).


## Навигация

Универсальная навигационная панель (Navbar) используется на всех страницах:
- **Главная** (`/`) — вход, регистрация, публичная библиотека
- **Публичная библиотека** (`/public`) — книги, серии, авторы с фильтрами
- **Профиль** (`/profile`) — мои книги, серии, загрузка новых
- **Уведомления** (`/notifications`) — лайки, комментарии, подписки
- **Админ-панель** (`/admin`) — управление контентом

На страницах книг, авторов и серий отображаются **breadcrumbs** (хлебные крошки) для удобной навигации.

## Админ-функции

Администратор имеет доступ к дополнительным функциям прямо из интерфейса:

- **Страница книги**: кнопки "Скрыть/Опубликовать", "Удалить"
- **Страница автора**: кнопки "Забанить", "Удалить пользователя"
- **Страница серии**: кнопка "Удалить серию"
- **Публичная библиотека**: фильтрация и модерация контента

Безопасность: все действия проверяются на сервере по JWT-токену и роли.
