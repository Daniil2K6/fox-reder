# FoxBooks (fox-reder)

Веб-читалка с личной библиотекой, поддержкой **FB2**, **EPUB**, **TXT** и формата **VoxBook** (`.vb` / `.vblite`), озвучкой через **Edge TTS** и социальной обвязкой.

Репозиторий: [github.com/Daniil2K6/fox-reder](https://github.com/Daniil2K6/fox-reder)

## Возможности

- **Учётные записи**: регистрация, вход, JWT-токены, роли (user/admin), Plus-подписка
- **Личная библиотека**: загрузка книг, дедупликация по SHA256, управление сериями (создание, обложка, описание, drag-and-drop порядок книг), редактирование метаданных
- **Читалка**: непрерывный режим и по главам, тёмная/светлая тема, настройки шрифта, локальный просмотр .vb/.vblite без загрузки
- **Озвучка**: Edge TTS — несколько языков и голосов
- **Публичная библиотека**: лента «Горячее», популярные серии (адаптивная сетка 5→2 колонок), рейтинг авторов (сайдбар на десктопе, встроенный блок на мобильных), пагинация книг (4×5 на стр. 1, 4×9 на стр. 2+) с сохранением страницы в URL (`?page=N`)
- **Социальные функции**: комментарии, лайки, подписки на авторов, уведомления
- **Анимированные обложки**: GIF/WebP — только для Plus-пользователей (проверка на сервере)
- **Админ-панель**: управление пользователями, баны, модерация книг и серий

## Быстрый старт

Требования: **Python 3.12+**, **Node.js 18+**.

### Linux / macOS

```bash
chmod +x run.sh
./run.sh --dev
```

### Windows

Дважды кликните по файлу `start.bat` или запустите из командной строки:

```cmd
start.bat start
```

Команды:
- `start.bat start` — запуск
- `start.bat stop` — остановка
- `start.bat restart` — перезапуск

- Фронтенд: [http://localhost:3000](http://localhost:3000)
- API (документация Swagger): [http://localhost:8000/docs](http://localhost:8000/docs)

Учётная запись администратора по умолчанию: **`admin` / `admin`**

### Запуск только бэкенда

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### Запуск только фронтенда

```bash
cd frontend
npm install
npm run dev
```

Прокси к API настроен в `frontend/next.config.js` (переписывание `/api/*` → `http://127.0.0.1:8000`).

## Навигация

Универсальная навигационная панель (Navbar) используется на всех страницах:
- **Главная** (`/`) — вход, регистрация, публичная библиотека
- **Публичная библиотека** (`/public`) — горячее, серии, авторы, книги с пагинацией и поиском
- **Профиль** (`/profile`) — мои книги, серии (создание/редактирование/удаление с обложкой и описанием), загрузка книг, настройки
- **Уведомления** (`/notifications`) — лайки, комментарии, подписки
- **Админ-панель** (`/admin`) — управление пользователями, модерация контента

На страницах книг, авторов и серий отображаются **breadcrumbs**.

## Публичная библиотека

- **Горячее**: 4 популярные книги на первой странице
- **Серии**: адаптивная сетка — 20 (xl) / 12 (lg) / 6 (md) / 4 (sm) карточек
- **Авторы**: сайдбар «Популярные авторы» на десктопе (с маской скролла), встроенный блок на мобильных (до 10 записей)
- **Книги**: 4 колонки, 20 книг на стр. 1, 36 на стр. 2+. Номер страницы сохраняется в `?page=N`
- **Фильтры**: поиск, сортировка, жанры, расширения (на отдельной вкладке «Книги»)

## Админ-функции

Администратор имеет доступ к дополнительным функциям прямо из интерфейса:
- **Страница книги**: кнопки «Скрыть/Опубликовать», «Удалить»
- **Страница автора**: кнопки «Забанить», «Удалить пользователя»
- **Страница серии**: кнопка «Удалить серию»
- **Публичная библиотека**: фильтрация и модерация

Безопасность: все действия проверяются на сервере по JWT-токену и роли.
